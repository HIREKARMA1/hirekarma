## 🎨 Design Reference

This project is based on the [HireKarma Landing Page Figma design](https://www.figma.com/design/H8AeCG3tepMnOCSQd8k4Xg/HireKarma-Landing-Page?node-id=1-2&p=f&t=tYoUTejVgiZBVmF7-0).

### Key Design Elements
- **Color Palette**: Professional color scheme with primary and secondary colors
- **Typography**: Geist Sans and Geist Mono font families
- **Layout**: Responsive grid system with mobile-first approach
- **Components**: Reusable UI components following design system principles
